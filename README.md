# Майстерня у Євгенія — Landing v2

Статична верстка (HTML / CSS / JS), готова до перенесення у WordPress.

## Структура
```
index.html
assets/
  css/main.css      — токени з Figma → компоненти → секції → responsive
  js/main.js        — уся логіка й анімації (GSAP + ScrollTrigger + Lenis)
  vendor/           — gsap 3.12.5, ScrollTrigger, lenis 1.1.13 (локально, без CDN)
  img/              — фото (див. «Що замінити»)
  svg/              — favicon, знак логотипу
  fonts/            — сюди покласти Kyiv*Type Serif (woff2)
```

## CSS-конвенції
- **Mobile first.** Базові стилі пишемо під телефон, а більші екрани додаємо тільки через `min-width`. Медіазапити стоять усередині своєї секції, одразу після її базових стилів.
- **Брейкпоінти:** `768px` (планшет), `1025px` (десктоп), `1201px` (конфігуратор у 3 колонки). Вони збігаються з `gsap.matchMedia` у `main.js`.
- **Шрифти тільки в rem**, fluid-розміри через `clamp(rem, vw, rem)`. Висоти кнопок теж у rem, щоб кнопка росла разом із текстом. Відступи й сітка в px.
- **Hero** масштабується від однієї змінної `--u` (`1em` = 72px на 1440, максимум 96px на 1920). Усі позиції контурних слів задані в `em`.

## Роботи й слайдер
- Дані робіт лежать в `index.html`, у `<script type="application/json" id="works-data">` одразу після сітки робіт. Для кожної роботи там є `title`, `material`, `description` і `photos[]` (`src`, `alt`).
- Картка `data-work="0…5"` відкриває роботу з тим самим індексом. Кількість фото на картці й aria-підпис рахуються з даних автоматично.
- Слайдер один для всіх робіт (`initViewer` у `main.js`). У ньому є стрілки, лічильник 01 / 06, свайп і перетягування, Esc, клік поза фото, блокування скролу, фокус усередині модалки й повернення фокуса на картку.
- Щоб наповнити роботу власними фото, заміни її масив `photos`. Зараз усі 6 робіт показують ті самі 6 фото, і першим іде фото відповідної картки.
- У WordPress цей JSON виводиться з ACF repeater (наприклад, через `wp_json_encode`).

## Шрифти
- **Kyiv*Type Serif** — підключено 3 накреслення як у макеті (woff2 + woff):
  `Regular2` → 400 (текст), `Medium2` → 500 (H1, кнопки, логотип), `Bold3` → 600–700 (заголовки).
  Решта файлів у `assets/fonts/` (eot, ttf, demo.html, stylesheet.css, інші накреслення) не використовуються.
- Montserrat, Comforter (підпис) — Google Fonts.

## WordPress
- `wp_enqueue_script('gsap', …/vendor/gsap.min.js)`, далі ScrollTrigger (deps: gsap), lenis і main.js (deps: gsap, scrolltrigger, lenis), усе в footer.
- Клас `js` на `<html>` ставиться інлайн-скриптом у `<head>`: він приховує елементи до reveal. Без JS усе показується статично.
- Секції — це окремі блоки (ACF Flexible Content або Gutenberg patterns): hero, about, heritage, works, process, config, gift, reviews, contact.

## Motion-система
| Секція | Ефект |
|---|---|
| Preloader | лічильник 0→100 → «жар» → шторка |
| Hero | reveal рядків, дим (canvas) з чаші люльки реагує на курсор, параллакс |
| Про мене | шторка на фото, маніфест проявляється слово за словом за скролом, лічильники |
| Традиція | вишивка хрестиком «прошивається» за скролом і дрейфує, 10% count-up |
| Роботи | шторки, параллакс у рамках; hover — рамка-паспарту, наближення, «N фото +»; слайдер роботи |
| Процес | горизонтальний pin-скрол із прогресом (desktop), свайп-слайдер (≤1024) |
| Конфігуратор | кроки, live-підсумок, анімована ціна, автозаповнення форми |
| Подарунок | кадр розкривається на весь екран за скролом |
| Відгуки | marquee з паузою на hover |
| Футер | безшовний бігучий рядок (CSS, клон з JS), люлька на передньому плані з паралаксом |

Підтримується `prefers-reduced-motion`: pin, smooth scroll, дим і scrub вимикаються.
